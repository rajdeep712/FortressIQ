### Code Formats

If you want to mention an inline command like `npm run dev`, use single backticks.

For larger, multi-line blocks of code, use triple backticks and specify the programming language for syntax highlighting:

```javascript
function greetUser(name) {
    console.log(`Hello, ${name}! Welcome to Markdown.`);
}
greetUser('Developer');
```

### Tables

You can create structured tables using vertical pipes `|` and hyphens `-`:
